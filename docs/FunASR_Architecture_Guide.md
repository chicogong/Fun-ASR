## 1. 项目概述

Fun-ASR-Nano 是一个基于 **Audio-LLM (语音大模型)** 架构的端到端语音识别系统。它将传统的 ASR 模型与大语言模型 (LLM) 结合，实现了更智能的语音转文字功能。

### 核心特点
- **多语言支持**: 中文、英文、日文等
- **热词增强**: 支持自定义热词列表提高识别准确率
- **文本规整 (ITN)**: 自动进行数字、日期等格式化
- **多轮对话**: 支持多轮对话上下文

### 架构组件说明

| 组件 | 模型 | 维度 | 作用 |
|------|------|------|------|
| Audio Encoder | SenseVoiceEncoderSmall | 512 | 提取音频特征 |
| Audio Adaptor | Transformer (2层) | 512→1024 | 对齐音频和文本特征空间 |
| LLM | Qwen3-0.6B | 1024 | 生成转写文本 |
| Frontend | WavFrontend | 80 mel | 音频预处理 |

## 6. 训练流程

### 6.1 Forward 流程图

```
┌─────────────────────────────────────────────────────────────────────────────────────┐
│                              训练 Forward 流程                                        │
├─────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                     │
│  输入 Batch:                                                                         │
│  ┌─────────────────────────────────────────────────────────────────────┐           │
│  │  speech: [B, T, 80]           - Fbank 特征                          │           │
│  │  speech_lengths: [B]          - 语音实际长度                         │           │
│  │  input_ids: [B, seq_len]      - Token 序列                          │           │
│  │  attention_mask: [B, seq_len] - 注意力掩码                          │           │
│  │  labels_ids: [B, seq_len]     - 训练标签 (源部分为-100)             │           │
│  │  fbank_beg: [B, turns]        - 语音起始位置                         │           │
│  │  fake_token_len: [B, turns]   - 语音token长度                        │           │
│  └─────────────────────────────────────────────────────────────────────┘           │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Step 1: 获取文本 embedding                                            │          │
│  │                                                                       │          │
│  │  input_ids[input_ids < 0] = 0  # 处理负值                            │          │
│  │  inputs_embeds = llm.get_input_embeddings()(input_ids)               │          │
│  │                                                                       │          │
│  │  inputs_embeds: [B, seq_len, 1024]                                   │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Step 2: 音频编码                                                      │          │
│  │                                                                       │          │
│  │  if speech is not None:                                               │          │
│  │      # 可选: activation checkpoint 节省显存                           │          │
│  │      if self.audio_encoder_activation_checkpoint:                    │          │
│  │          encoder_out, lens = checkpoint(self.encode, speech, lens)   │          │
│  │      else:                                                            │          │
│  │          encoder_out, lens = self.encode(speech, speech_lengths)     │          │
│  │                                                                       │          │
│  │      # 经过 adaptor                                                   │          │
│  │      encoder_out, lens = self.audio_adaptor(encoder_out, lens)       │          │
│  │                                                                       │          │
│  │  encoder_out: [B_speech, T'', 1024]                                  │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Step 3: 融合音频 embedding                                            │          │
│  │                                                                       │          │
│  │  speech_idx = 0                                                       │          │
│  │  for batch_idx in range(batch_size):                                 │          │
│  │      for turn_id in range(fbank_beg.shape[1]):                       │          │
│  │          fbank_beg_idx = fbank_beg[batch_idx, turn_id]               │          │
│  │          if fbank_beg_idx > 0:                                        │          │
│  │              speech_token_len = fake_token_len[batch_idx, turn_id]   │          │
│  │              speech_token = encoder_out[speech_idx, :speech_token_len]│          │
│  │              inputs_embeds[batch_idx,                                 │          │
│  │                           fbank_beg_idx:fbank_beg_idx+speech_token_len]│          │
│  │                           = speech_token                              │          │
│  │              speech_idx += 1                                          │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Step 4: LLM Forward                                                   │          │
│  │                                                                       │          │
│  │  with torch.autocast(dtype=bf16):                                     │          │
│  │      labels_ids[labels_ids == -1] = -100  # 忽略源部分                │          │
│  │      attention_mask[attention_mask < 0] = 0                          │          │
│  │                                                                       │          │
│  │      model_outputs = self.llm(                                        │          │
│  │          inputs_embeds=inputs_embeds.to(bf16),                       │          │
│  │          attention_mask=attention_mask,                               │          │
│  │          labels=labels_ids                                            │          │
│  │      )                                                                │          │
│  │                                                                       │          │
│  │      loss = model_outputs.loss                                        │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ Step 5: 计算统计信息                                                   │          │
│  │                                                                       │          │
│  │  # 计算准确率                                                          │          │
│  │  preds = torch.argmax(model_outputs.logits, -1)                      │          │
│  │  acc = compute_accuracy(preds[:, :-1], labels_ids[:, 1:], ignore=-100)│          │
│  │                                                                       │          │
│  │  stats = {                                                            │          │
│  │      "loss": loss.detach(),                                           │          │
│  │      "acc": acc,                                                      │          │
│  │      "batch_size": batch_size,                                        │          │
│  │      "batch_size_speech": batch_size_speech,                         │          │
│  │      "batch_size_x_frames": frames * batch_size_speech,              │          │
│  │      "batch_size_real_frames": speech_lengths.sum(),                 │          │
│  │      "padding_frames": ...,                                           │          │
│  │      "dialog_turns_max": ...,                                         │          │
│  │      "dialog_turns_avg": ...                                          │          │
│  │  }                                                                    │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│         │                                                                           │
│         ▼                                                                           │
│  ┌──────────────────────────────────────────────────────────────────────┐          │
│  │ 返回                                                                   │          │
│  │                                                                       │          │
│  │  return loss, stats, weight                                           │          │
│  └──────────────────────────────────────────────────────────────────────┘          │
│                                                                                     │
└─────────────────────────────────────────────────────────────────────────────────────┘
```

```python
output = {
    # 音频相关
    "speech": torch.Tensor,           # [1, T, 80] Fbank特征

    # Token相关
    "input_ids": torch.Tensor,        # [1, seq_len] 完整token序列
    "attention_mask": torch.Tensor,   # [1, seq_len] 全1
    "labels_ids": torch.Tensor,       # [seq_len] 源部分-100, 目标部分为token id

    # 辅助

    "target_ids": torch.Tensor,       # [1, tgt_len] 仅目标序列
```

### 7.3 配置参数说明

```yaml
# 模型配置
model: FunASRNano
```
